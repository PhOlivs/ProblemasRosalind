# Bioinformática

Repositório dedicado ao estudo de **Bioinformática** por meio da resolução de problemas da plataforma [Rosalind](https://rosalind.info/).

O projeto tem como objetivo desenvolver, de forma progressiva, conhecimentos de programação, algoritmos e conceitos fundamentais de biologia molecular, utilizando problemas práticos como forma de aprendizado.

## Objetivos

- Desenvolver programação em Python aplicada à Bioinformática
- Praticar algoritmos e estruturas de dados
- Trabalhar com sequências biológicas
- Compreender conceitos de Biologia Molecular e Genética
- Analisar complexidade e eficiência de algoritmos
- Desenvolver testes automatizados
- Praticar boas práticas de organização e documentação
- Construir um histórico de aprendizado e projetos para portfólio

## Configuração

O projeto utiliza Python em um ambiente virtual isolado para evitar interferências com o Python do sistema.

## Linux/macOs

Para criar o ambiente:

```bash
python -m venv .venv
```

Para ativá-lo no Linux:

```bash
source .venv/bin/activate
```

As dependências utilizadas pelo projeto estão registradas em:

```text
requirements.txt
```

Para instalá-las:

```bash
python -m pip install -r requirements.txt
```

## Windows - PowerShell

Para criar o ambiente:

```bash
python -m venv .venv
```

Para ativá-lo no Windows

```bash
.\.venv\Scripts\Activate.ps1
```

As dependências utilizadas pelo projeto estão registradas em:

```text
requirements.txt
```

Para instalá-las:

```bash
python -m pip install -r requirements.txt
```

## Metodologia

Cada problema é tratado como uma pequena etapa de estudo.

O processo envolve:

```text
Problema
   ↓
Compreensão
   ↓
Modelagem
   ↓
Implementação
   ↓
Testes
   ↓
Análise de complexidade
   ↓
Documentação
   ↓
Git / GitHub
```

A intenção não é apenas obter uma resposta correta, mas compreender o problema, justificar a abordagem utilizada e desenvolver soluções claras, corretas e eficientes.
