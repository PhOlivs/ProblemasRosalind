# Counting DNA Nucleotides

Problema da plataforma Rosalind sobre a contagem dos nucleotídeos presentes em uma sequência de DNA.

## Objetivo

Dada uma sequência de DNA, determinar quantas vezes cada um dos quatro nucleotídeos aparece:

- Adenina (`A`)
- Citosina (`C`)
- Guanina (`G`)
- Timina (`T`)

A resposta deve apresentar as quatro quantidades nessa ordem.

## Entrada

Uma sequência de DNA contendo apenas os símbolos:

```text
A C G T
```

## Saída

Quatro números inteiros representando, respectivamente, a quantidade de:

```text
A C G T
```

## Exemplo

### Entrada

```text
AAAACCCGGT
```

### Saída

```text
4 3 2 1
```

## Abordagem

A solução será implementada em Python.

O objetivo é utilizar o problema para praticar:

- Manipulação de strings
- Iteração sobre sequências
- Contagem de elementos
- Entrada e saída de dados
- Complexidade de algoritmos
